# Bible Learning 📖

A simple, accessible Bible verse learning website designed to help learners practice reading scripture in a supportive environment.

## Features

✨ **Easy to Use**
- Large, readable text
- Simple navigation
- High contrast design

🔊 **Audio Support**
- Click "Read Aloud" to hear verses
- Slower speech for better learning

📱 **Mobile Friendly**
- Works on phones, tablets, and computers

## How to Use

1. Open the website
2. Read the verse
3. Click "Read Aloud" to hear it
4. Use Previous/Next buttons to go through verses
5. Practice daily!

Made with ❤️ for learning Scripture.
